# API Testing: Basic REST Requests & Responses Examples

**Цель:** Продемонстрировать понимание основ REST API, HTTP-методов, структуры JSON и кодов состояния на практике.

**Инструмент:** Postman / Браузер Chrome v115

## 1. Тестирование GET-запроса (Получение данных)
- **Endpoint (URL):** `https://jsonplaceholder.typicode.com/users/1`
- **Метод:** GET
- **Описание:** Запрос данных конкретного пользователя по его ID.
- **Ожидаемый результат:** Сервер возвращает статус `200 OK` и объект пользователя в формате JSON.
- **Фактический результат:** Статус `200 OK`. Получен JSON с полями `id`, `name`, `email`, `phone`. Данные соответствуют ожидаемым.
