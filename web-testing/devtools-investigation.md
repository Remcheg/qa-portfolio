# Web Testing: DevTools Investigation Example

**Цель:** Продемонстрировать навык использования браузерных инструментов разработчика (DevTools) для анализа UI и сетевых запросов.

**Инструмент:** Google Chrome DevTools (F12)

## 1. Анализ DOM-дерева (Вкладка Elements)
- **Действие:** С помощью инструмента "Inspect" был выбран элемент <h1 class="eKcvUb">Каждый день&nbsp;– День Земли</h1>". "День Земли" было заменено на "Рэм был тут".
- **Наблюдение:** Элемент представлен тегом `<h1>`. 
- **Эксперимент:** Текст внутри тега был изменен локально. Изменение мгновенно отразилось в интерфейсе браузера, что подтверждает связь DOM-дерева с отображаемым UI.

## 2. Анализ сетевых запросов (Вкладка Network)
- **Действие:** Страница была обновлена при открытой вкладке Network.
- **Наблюдение:** Зафиксировано 80 запросов к серверу. 
- **Детали запроса:** Был изучен запрос к https://lh3.googleusercontent.com/ogw/AF2bZyg55oZkEiqoNF8Th3VkbDrVHTNECu1LCMFlpwEu3Fj5-bY=s64-c-mo, "логотипу".
  - **Метод:** GET
  - **Status Code:** 200 OK
  - **Вывод:** Сервер успешно обработал запрос и вернул ожидаемый ресурс.

## Почему это важно для QA?
Использование DevTools позволяет не просто констатировать факт бага ("не работает"), а предоставить разработчикам технический контекст: какой именно элемент сломан, какая CSS-стилизация применяется, или какой сетевой запрос завершился ошибкой (4xx или 5xx).
