# SQL Basics: QA Cheatsheet

**Цель:** Продемонстрировать понимание базовых SQL-запросов, необходимых тестировщику для проверки данных в базе данных (БД).

**Инструмент:** DBeaver / pgAdmin / любой SQL-клиент

---

## 1. Простая выборка данных (SELECT + WHERE)
**Задача:** Найти пользователя с конкретным email в таблице `users`.

```sql
SELECT id, name, email 
FROM users 
WHERE email = 'rem@test.com';
```

**Почему это важно для QA:** Позволяет быстро проверить, действительно ли новый пользователь, зарегистрированный через сайт, корректно сохранился в базе данных.

---

## 2. Фильтрация данных (WHERE с условиями)
**Задача:** Найти все товары дороже 100 в таблице `products`.

```sql
SELECT name, price 
FROM products 
WHERE price > 100;
```

**Почему это важно для QA:** Полезно для проверки каталогов и фильтров на сайте. Если фильтр на сайте показывает товар за 50€, а должен только за 100€+, QA может проверить БД этим запросом и понять, где ошибка.

---

## 3. Объединение таблиц (JOIN)
**Задача:** Получить список всех заказов для пользователя с email 'rem@test.com', объединив таблицы `users` и `orders`.

```sql
SELECT users.name, users.email, orders.order_id, orders.amount
FROM users
JOIN orders ON users.id = orders.user_id
WHERE users.email = 'rem@test.com';
```

**Почему это важно для QA:** Данные часто лежат в разных таблицах. При баге с "пропавшим заказом" QA должен уметь написать JOIN-запрос, чтобы доказать разработчику, что данные в БД есть, и проблема именно в отображении на сайте.
